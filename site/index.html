VS CODE IS THE PC APP

Install once. Let runtrol find the CLIs.

There is no separate desktop window to manage. Runtrol Studio lives where the work already happens and discovers supported installed CLIs at runtime.

  1. 01
    Install Runtrol Studio

    Install the signed extension from the Visual Studio Marketplace.

  2. 02
    Open the Runtrol activity icon

    The session manager opens inside your current VS Code window.

  3. 03
    Use the CLIs you already have

    Supported installations, versions, models, flags, and capabilities are discovered instead of hardcoded.

  4. 04
    Select a session and keep moving

    The workspace follows your selection and cold sessions resume through their provider-native identity.

THIN BY DESIGN

The supervisor stays out of the conversation.

01

Provider-owned history

runtrol transports process events. It never keeps a second transcript or rewrites meaning.

02

Runtime discovery

Providers, versions, models, flags, and session paths come from the installed CLI at runtime.

03

Remote default deny

Phone control is scoped, paired, and encrypted. Model credentials never cross runtrol.
